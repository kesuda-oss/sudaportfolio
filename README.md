# Wall jump man

## 概要
Unityで開発した2Dアクションゲームです。
プレイヤーは壁を蹴ることでジャンプする壁ジャンプを活用して頂上にあるゴールを目指します。

## 制作目的
「geting over it」や「ジャンプキング」などといった高難度2Dゲームを作ってみたいと思い制作に至りました。

## 主な機能
- プレイヤー移動
左 A 右 D ジャンプ Space
-Time保管機能

## 使用技術
- Unity
- C#
- NavMesh
- Animator

## 工夫した点
このゲームではマリオようなチェックポイントがないためミスをすると最悪初めからスタートすることになります。これによりゴールしたときの達成感を大幅に増幅します。
そしてドキドキハラハラするプレイヤー体験を得られるよう工夫しました。またやり込み要素としてタイムを競うタイムアタックを追加し、継続して遊び続けられよう工夫しています。ステージ理解、プレイヤーの挙動理解
を深め、最速タイムを更新していってください。　※現在の最速タイムは40秒です。

## 実行方法
1. リポジトリをクローン
2. Unityで開く
3. AssetsのSampleSenceをHierarchyにドラッグアンドドロップ
4. Playをクリックしてスタート
